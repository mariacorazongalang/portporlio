# Ma.Corazon June L. Galang — Professional Portfolio

Personal portfolio of a 3rd-year BS Information Technology student at Northeastern College. It presents my skills, projects, professional development certificates, and resume.

**Live site:** _add your link here after publishing_

## Features
- **Dark and light mode**: follows the device setting, remembers the visitor's choice, and switches with an animated circle reveal (View Transitions API)
- **Certificate viewer**: full-screen viewer with keyboard arrows, swipe on phones, and a download button
- **Certificate filters**: filter by organizer, with animated cards and live counts
- **Resume preview**: view the resume on the page or download the PDF
- **Command menu**: press `Ctrl K` (or `/`) to search sections, actions, and every certificate
- **Professional development timeline** from July to October 2026
- **Bento grid layout**, scrolling skills strip, and an animated hero background with a dot grid that reacts to the mouse
- **Typing effect**, count-up stats, scroll progress bar, and scroll-triggered animations
- **Responsive** on phones, tablets, and desktops
- **Accessible**: works with the keyboard alone, respects "reduce motion" settings, and still shows all content without JavaScript

## Built with
Plain **HTML, CSS, and JavaScript**, with no frameworks or libraries.

| File | Purpose |
|---|---|
| `index.html` | Page content and structure |
| `style.css` | Layout, themes (CSS variables), animations, responsive design |
| `script.js` | Interactive features, one commented section per feature |
| `assets/` | Certificates, resume, and images |

## Run locally
Download the files and open `index.html` in a browser.
